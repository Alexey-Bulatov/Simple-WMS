# Simple WMS

Автономная система адресного складского управления. Основной складской цикл
работает без обязательного подключения ERP; интеграции подключаются отдельными
адаптерами.

Текущая версия содержит рабочую прослеживаемость складского цикла:

1. фиктивная номенклатура и партия;
2. генерация уникальных коробок;
3. приемка коробки от производства;
4. формирование однородной палеты;
5. закрытие палеты;
6. размещение в адресную ячейку;
7. перемещение палеты;
8. неизменяемый журнал операций.

Также реализованы отгрузка, межскладская передача, инвентаризация, очередь
заданий, карточки объектов, карта склада, импорт справочников, PDF-этикетки и
печать на проверенном профиле сетевого термопринтера. Универсальная модель
логистических единиц поддерживает пользовательские типы тары, дробные
количества, содержимое, безопасную вложенность, приёмку, блокировку, карантин,
адресное размещение, перемещение, отгрузку и межскладскую передачу. Новое ядро
доступно через API; рабочий интерфейс пока использует демонстрационные модели.

## Быстрый локальный старт

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.seed
uvicorn app.main:app --reload
```

API будет доступен на `http://127.0.0.1:8000`.

Документация FastAPI: `http://127.0.0.1:8000/docs`.

## Интерфейсы

- `/` и `/work` — основное рабочее место с пошаговыми операциями;
- `/tech` — техническое оглавление всех экранов пилота;
- `/scan`, `/shipments`, `/transfers`, `/inventory`, `/catalog`, `/map` — полные технические экраны.

## PostgreSQL

Для Debian-сервера укажите PostgreSQL URL в `.env`:

```bash
DATABASE_URL=postgresql+psycopg://wms:wms_password@127.0.0.1:5432/wms
```

Схема базы управляется Alembic. Приложение выполняет `alembic upgrade head` при старте.

```bash
alembic current
alembic check
alembic revision --autogenerate -m "описание изменения"
alembic upgrade head
```

Кандидат миграции после `--autogenerate` необходимо просмотреть вручную. Порядок
резервного копирования и проверки восстановления описан в `docs/backup-restore.md`.

## Архитектурный принцип

UI, сканер-клавиатура, мобильная страница и печать этикеток должны вызывать backend-операции. Запреты должны находиться на backend-уровне:

- коробка не может быть принята дважды;
- коробка не может входить в две палеты;
- палета не может содержать разные партии и номенклатуры без специального режима;
- палета не может размещаться в занятую ячейку сверх емкости;
- ручные изменения должны оформляться как операции с причиной и журналом.
