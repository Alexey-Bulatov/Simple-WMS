# Замороженный WMS Pilot

Этот каталог содержит самодостаточный снимок демонстрационного пилота на
3 августа 2026 года. Исходная точка также зафиксирована Git-тегом
`pilot-freeze-2026-08-03` на коммите `aa34b24`.

Пилот сохранён для повторного показа, проверки старых сценариев и сравнения при
миграции. Новые функции здесь не разрабатываются. Текущий продукт Simple WMS
находится в корне репозитория.

## Локальный запуск снимка

```bash
cd legacy/pilot
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
python -m app.seed
uvicorn app.main:app --port 8001
```

Для воспроизведения рабочего серверного контура необходимо использовать
отдельную базу данных и отдельный порт. Нельзя направлять пилот на продуктивную
базу Simple WMS.
